# Breeding Vat: Application Spine

## 1. Entrypoints
- **setup.bat / run.bat**: Canonical Windows entrypoints delegating to `scripts/manager.py`.
- **scripts/manager.py**: Orchestrates image builds, container lifecycles, and model downloads.

## 2. Core Orchestration
- **TaskRunner (`breeding_vat/orchestrator/runner.py`)**: The DooD (Docker-out-of-Docker) manager. Launches sibling containers.
- **MergekitEngine / FusionBenchEngine**: Specialized wrappers that generate YAML/commands for worker containers.

## 3. The UI (Streamlit)
- **app.py**: The primary dashboard. Communicates with `ExperimentManager` and `EvolutionEngine`.
- **ExperimentManager**: Manages the SQLite database (`breeding.db`) and filesystem metadata for experiments.

## 4. The Evolution Loop
- **EvolutionEngine (`breeding_vat/modules/merge/evolution.py`)**: Implements the waterfall merging logic (Merge -> Evaluate -> Cull -> Repeat).
- **EvolutionWithLogging**: A decorator/wrapper that adds persistence and UI progress callbacks to the evolution loop.

## 5. Knowledge/State
- **system_state.json**: Generated by `scripts/state_analyzer/`. Provides ground truth for the LLM/Agent to understand connections.
